## Included and excluded

- English/Chinese README entry pages and sanitized technical references for all 14 repositories.
- A repeatable documentation checker and tests; supporting guides no longer contain the removed private deployment records.
- English installer generation and tests, bilingual platform information, separate Chinese/English OSS videos, and the installation website's copyright/filing footer.
- Existing locally built AbilityFramework/Wheel files and their LFS backups are preserved but not committed.
- No new business binary archive, package-version upgrade, or OSS stable-pointer update is part of this public source snapshot.
