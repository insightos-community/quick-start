# Maintenance update v0.1.3

This update keeps the existing business baseline. It does not select the leading
upstream framework or SDK versions.

- Installer fixes from v0.1.2: package-index downloads of hash-pinned third-party
  Wheels, special-Wheel LFS fallback, offline cache verification and clearer sudo
  authentication failures.
- Restore the approved R1 Pro maintenance models through Git LFS, following the
  project owner's confirmation on 2026-09-10. Third-party attribution is preserved;
  the repository's Apache-2.0 license does not relicense the models.
- Pin `mujoco-asset` to `v0.4.0-insightos.2026.3`, commit
  `f9855e6dd1419f890b418a9f398bd1d5ec49b57c`. Other component pins are unchanged.
- Step 2.4 validates model entry files and referenced payloads. The artifact
  packager permits only the four restored R1 Pro variants and includes their
  provenance/license-scope notices. No new binary archive or website release is
  produced by this source update.

After updating quick-start, rerun steps 2.2, 2.3 and 2.4. The older asset tag
intentionally has no R1 Pro model payloads. Do not replace the pinned models with
newer upstream files without a separate compatibility review.
