musl 运行时：包内或宿主（可选）

Linux x86_64 可通过 --musl 选择额外安装包，默认使用包内 musl，也支持 glibc 宿主。默认安装方式不变；请使用独立目录。

curl -fsSL https://semantic.insightos.cn/install.sh | bash -s -- \
  --musl --musl-runtime bundled --install-system-deps --dir "$HOME/semantic-musl"

--musl-runtime bundled 使用包内 musl 1.2.5；--musl-runtime system 使用宿主已安装的 musl 1.2+ 加载器。随包提供 CPython 3.13.15、NumPy 2.3.5、机器人依赖和 Mesa，无需编译源码。不会修改系统 /lib 或软件源；切换运行时请使用新目录。

默认自动选择可用的 Mesa GPU，失败时回退到软件渲染。增加 --render-backend software 可强制软件渲染；--render-backend mesa-gpu 要求硬件渲染成功。AMD 已实测；Intel / Nouveau 尚未实机验证。NVIDIA 专有驱动请使用默认 glibc 安装。

GET UP AND RUNNING

接下来，开始运行。

默认安装至 ~/.local/share/semantic。
在自己的机器上安装，请勿在本网站输入凭据。

1

选择目录，安装环境

上方命令使用交互式确认。自动安装可增加 --yes；自定义目录使用绝对路径。

curl -fsSL https://semantic.insightos.cn/install.sh | bash -s -- \
  --yes --install-system-deps --dir "$HOME/semantic"

依赖安装支持 apt-get、dnf/yum、pacman、zypper；musl / Alpine 使用 APK。沿用机器已有的源，不会升级整个系统。

2

打开你的控制台

新安装默认同时支持本机 http://127.0.0.1:3000 与局域网 http://主机IP:3000，用户名 admin。安装完成页会在交互终端显示随机密码，并将密码保存在实例目录的 configs/secrets.json，不会写入安装日志。

Web 默认监听 0.0.0.0:3000；可用 --web-host 127.0.0.1 限制为仅本机，或用 --web-port 自定义端口。仅向可信局域网放行 Web 端口，API/WS 保持仅本机。公网推荐 HTTPS 反向代理或 SSH 隧道。

3

检查服务，配置任务

~/.local/share/semantic/bin/semanticctl status
~/.local/share/semantic/bin/semanticctl doctor
~/.local/share/semantic/bin/semanticctl logs

自定义安装目录时请替换上述路径。默认模型配置为 mock，真实模型需另行配置；不会自动创建业务任务或启动真实机器人。

BEFORE YOU INSTALL

先确认，后部署。

当前仅支持 Linux x86_64。应用主程序采用静态构建，但 Python、MuJoCo Wheel 与图形运行库仍有系统依赖。

已验证系统Ubuntu 24.04（默认）；Ubuntu 22.04 / Alpine 3.23（--musl，Linux x86_64）
兼容性边界默认安装以 glibc ≥ 2.28 为基线；--musl 默认使用包内运行时，可用于 glibc 或 musl 宿主；system 模式需要宿主 musl 1.2+。其他发行版需验证；当前不支持 macOS、Windows 或 ARM64。
下载与更新中文默认从阿里云 OSS 下载，英文默认从 GitHub Releases 下载；--musl 在两种语言下均默认使用 GitHub Releases。下载后校验 SHA-256。跨版本或 glibc / musl 切换请使用新目录并显式迁移数据。
GOOD TO KNOW

常见问题

已经安装，如何开启局域网访问并创建桌面入口？

下面命令只更新管理工具、监听配置和桌面入口，不升级业务版本，不重新部署数据库或运行包。请替换为实际安装目录。

curl -fsSL https://semantic.insightos.cn/install.sh | bash -s -- \
  --configure-existing --dir "$HOME/.local/share/semantic" --lan --desktop-shortcut

快捷入口使用 InsightOS 图标，打开本机 Web。没有桌面环境时可省略 --desktop-shortcut；桌面如提示不受信任，请选择“允许启动”。添加完成页提供的 PATH 后，可用 semanticctl welcome 再次查看地址与终端密码。

如何卸载？数据会被删除吗？

先停止场景与 Robot Runtime。默认卸载保留配置、数据和日志；先用 --dry-run 查看计划。请将目录替换为实际的绝对安装路径。

curl -fsSL https://semantic.insightos.cn/install.sh -o semantic-install.sh
bash semantic-install.sh --uninstall --dir "$HOME/.local/share/semantic" --dry-run
bash semantic-install.sh --uninstall --dir "$HOME/.local/share/semantic"

新版管理工具也可运行 semanticctl uninstall。若提示终端占用，请在对应终端执行 cd ~；已删除的工作目录不会阻塞卸载，不需要 kill。只有显式增加 --purge 并确认后，才会永久删除该实例的全部内容。系统软件包不会被卸载。

安装遇到问题，应该检查什么？

检查 Python 版本、系统架构、磁盘空间与网络连通性。安装后的运行日志位于实例的 logs/；使用 semanticctl doctor 诊断环境。安装脚本参数可通过 bash semantic-install.sh --help 查看。

这是线上机器人控制台吗？

不是。这是 Semantic 的介绍与安装入口，静态站点不运行你的机器人服务。控制台、模型密钥与机器人数据都属于你自行部署的实例。请为生产使用另行配置访问控制、网络隔离和备份。
